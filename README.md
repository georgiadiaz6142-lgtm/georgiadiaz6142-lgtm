## ✨ Latest build

### 🗺️ [知源星图 · SourceAtlas](https://github.com/georgiadiaz6142-lgtm/source-atlas-desktop)

> 一个本地优先的 AI 无限画布桌面应用，用于组织文件、知识库、关系连线和 AI 分析结果。

- 🧠 在无限画布上组织文件、知识节点、关系与 AI 分析
- 📚 解析 PDF、DOCX、Markdown、TXT、HTML，并支持本地全文检索
- 🔐 原始资料、索引与工作区默认保留在本机，API Key 使用系统安全存储
- 🤖 支持 OpenAI、DeepSeek 及 OpenAI 兼容接口
- 🍎 可打包为 macOS 桌面应用
